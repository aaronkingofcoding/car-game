코인 카 러시 실행 방법

1. index.html 파일을 더블 클릭해 웹 브라우저에서 엽니다.
2. 게임 시작을 누릅니다.
3. A/D 키 또는 왼쪽/오른쪽 방향키로 자동차를 움직입니다.
4. 노란 코인을 얻고, 빨간 장애물 자동차를 피하세요.
5. 코인 5개를 모은 뒤 스페이스바 또는 '속도 +0.1' 버튼으로 터보를 사용할 수 있습니다. 사용할 때마다 코인 5개가 소비되고 속도가 0.1씩 오릅니다. 속도에는 상한이 없습니다.
6. 코인은 세로 줄, 가로 줄, 지그재그, 대각선 등 7가지 패턴으로 자주 등장합니다.

별도 설치나 인터넷 연결 없이 실행됩니다. (처음 화면의 글꼴은 인터넷 연결 시 더 예쁘게 표시됩니다.)
